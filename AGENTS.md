# AGENTS.md

## Назначение

Неофициальный демонстрационный одностраничник мастерской «БеZвмятин». До согласования с владельцем сайт должен оставаться закрытым от индексации и явно помеченным как демонстрационный.

## Архитектура

- `src/config/site.ts` — название, контакты, услуги, процесс, факторы стоимости, FAQ и CTA.
- `src/styles/theme.css` — цвета, шрифты, отступы и границы.
- `src/styles/main.css` — композиция и адаптивность.
- `src/main.ts` — разметка, мобильное меню, FAQ, локальный выбор файлов и валидация формы.
- `dist/` — production build для GitHub Pages.

## Контентные ограничения

- Не добавлять вымышленные цены, сроки, гарантии, отзывы и количественные показатели.
- Не использовать чужие фотографии и логотипы без разрешения.
- Не менять подтверждённый телефон `+7 903 647-25-92` без надёжного источника.
- Не фиксировать корпус здания без подтверждения владельца.
- Демо-форма не отправляет данные и не загружает файлы.

## Anti-vibecode

Интерфейс должен быть простым и коммерчески понятным. Запрещены декоративные SVG-автомобили, стоковые изображения, bento grid, светящиеся объекты, glassmorphism, dashboard-композиции, три тарифа, одинаковые feature-карточки и избыточные интерактивы.

## Проверки

```bash
npm install
npm run lint
npm run typecheck
npm run test
npm run build
```

Дополнительно проверить ширины 360, 390, 768, 1024, 1440 и 1920 px, мобильное меню, FAQ, форму, выбор файлов, ошибки и focus-state.
