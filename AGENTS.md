# AGENTS.md

## Назначение репозитория

Это неофициальный демонстрационный концепт одностраничного сайта мастерской «БеZвмятин». Проект предназначен для закрытой коммерческой демонстрации и не должен создавать впечатление официального сайта до письменного согласования с владельцем.

## Технические правила

- Использовать Vanilla HTML, CSS и JavaScript без сборки и внешних UI-зависимостей.
- Сохранять работоспособность по пути `/bezvmyatin/` на GitHub Pages.
- Не добавлять фейковые отзывы, цены, сроки, гарантии, сертификаты или фотографии работ.
- Не менять подтверждённый телефон `+7 903 647-25-92` без нового источника.
- Не фиксировать точный корпус в адресе без подтверждения владельца: публичные источники расходятся между `3В` и `3И`.
- Сохранять видимую маркировку «демонстрационный концепт» и мета-тег `noindex`.
- Фотографии из формы не должны незаметно загружаться на сторонние сервисы.
- Все интерактивные элементы должны работать с клавиатуры и иметь видимый focus state.
- Поддерживать ширины от 320 px; не допускать горизонтального скролла.
- Учитывать `prefers-reduced-motion`.

## Проверки перед коммитом

```bash
node --check assets/app.js
python3 -m http.server 4173
```

Проверить вручную:

1. мобильное меню;
2. навигацию по якорям;
3. ползунок «до / после»;
4. выбор и удаление до четырёх фото;
5. валидацию формы;
6. формирование текста WhatsApp;
7. ссылки телефона и Яндекс Карт;
8. отсутствие переполнения на 390, 768, 1024 и 1440 px.

## Коммерческий запуск

Перед снятием `noindex` заменить демонстрационные визуализации реальными материалами, согласовать контент, добавить юридические документы, Метрику, цели и официальный обработчик заявок.
