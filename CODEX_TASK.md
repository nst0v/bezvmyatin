# Задача для Codex: БеZвмятин — коммерческий демонстрационный одностраничник

## Цель

Довести существующий концепт до уровня убедительной персональной демонстрации для владельца мастерской беспокрасочного удаления вмятин «БеZвмятин» во Владимире. Сайт должен выглядеть как работа сильной небольшой студии, а не как шаблон или результат случайного вайб-кодинга.

## Текущий результат

В `main` уже реализованы:

- адаптивный одностраничник;
- тёмная индустриальная визуальная система с жёлтым акцентом;
- hero-блок, услуги, интерактив «до / после», процесс, кейсы, отзывы, FAQ и контакты;
- форма предварительной оценки с локальным выбором фотографий;
- переход в WhatsApp с готовым текстом обращения;
- маркировка неофициального демо и запрет индексации.

## Следующая итерация

1. Проверить визуальную иерархию на 390, 768, 1024 и 1440 px.
2. Устранить любое переполнение, скачки layout и слишком плотные участки текста.
3. Усилить hero без добавления неподтверждённых фактов.
4. Сделать форму максимально простой: понятные состояния focus, invalid, загрузки и удаления фотографий.
5. Проверить мобильное меню, FAQ, slider и WhatsApp-flow.
6. Оптимизировать CSS и JavaScript без ухудшения читаемости.
7. Сохранить Lighthouse-ориентиры: Performance ≥ 90, Accessibility ≥ 95, Best Practices ≥ 95, SEO не оценивать из-за осознанного `noindex`.
8. Не использовать внешние UI-библиотеки, тяжёлые анимации или стоковые изображения автомобилей.
9. Не выдумывать отзывы, цены, гарантии, сроки, сотрудников и количественные показатели.
10. Подготовить отдельный список данных, которые необходимо запросить у владельца для официального запуска.

## Обязательные ограничения

Следовать `AGENTS.md`. Телефон, демонстрационная маркировка и `noindex` не удалять. Расхождение адреса `3В / 3И` не разрешать догадкой.

## Критерии приёмки

- страница открывается по относительным путям на `/bezvmyatin/`;
- JavaScript проходит `node --check assets/app.js`;
- нет ошибок в консоли при обычном сценарии;
- все CTA ведут к звонку, фотооценке, WhatsApp или карте;
- выбранные фотографии не отправляются без явного действия пользователя;
- интерфейс доступен с клавиатуры;
- на мобильном есть удобный фиксированный CTA;
- репозиторий остаётся пригодным для GitHub Pages без стадии сборки.
