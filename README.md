# БеZвмятин — демонстрационный концепт одностраничного сайта

Премиальный адаптивный лендинг для мастерской беспокрасочного удаления вмятин во Владимире.

> **Статус:** неофициальный коммерческий концепт. Репозиторий и опубликованная страница не принадлежат компании «БеZвмятин», не принимают платежи и закрыты от индексации.

## Что реализовано

- адаптивный одностраничный интерфейс без UI-фреймворков;
- первый экран с понятным оффером и двумя CTA;
- интерактивное сравнение поверхности «до / после»;
- форма предварительной оценки повреждения;
- выбор до четырёх фотографий без загрузки на сторонний сервер;
- генерация готового обращения и переход в WhatsApp;
- услуги, процесс, демонстрационные кейсы, социальное доказательство, FAQ и контакты;
- мобильное меню, фиксированные мобильные действия, клавиатурная навигация и `prefers-reduced-motion`;
- `robots.txt`, `noindex` и явная маркировка демонстрационного статуса.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

## Проверка перед коммерческим использованием

До передачи компании необходимо:

1. получить разрешение на использование названия, логотипа, фотографий и отзывов;
2. заменить демонстрационные иллюстрации на реальные фотографии работ «до / после»;
3. подтвердить адрес, график, список услуг, гарантии и юридические реквизиты;
4. подключить реальный обработчик формы, Метрику и цели;
5. добавить политику обработки персональных данных;
6. снять `noindex` только после одобрения владельца и подключения официального домена.
