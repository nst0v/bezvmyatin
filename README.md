# БеZвмятин — простой коммерческий демо-сайт

Неофициальный одностраничный концепт для мастерской удаления вмятин без покраски во Владимире.

Сайт намеренно сделан без SVG-иллюстраций автомобилей, стоковых фотографий, декоративных эффектов и перегруженных интерактивов. Основной сценарий: человек понимает услугу, узнаёт, какие фотографии подготовить, и формирует локальный черновик обращения.

## Секции

- конкретный первый экран;
- памятка по трём фотографиям;
- основные виды повреждений;
- последовательность работы;
- факторы, влияющие на стоимость;
- демонстрационная форма с выбором файлов;
- FAQ;
- контакты.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:4173`.

## Проверки

```bash
npm run check
```

Команда запускает lint, TypeScript, тесты и production build.

## Где менять данные

- контент и контакты: `src/config/site.ts`;
- дизайн-токены: `src/styles/theme.css`;
- композицию: `src/styles/main.css`;
- интерактивность: `src/main.ts`;
- SEO и noindex: `src/index.html`.

## Публикация

Workflow `.github/workflows/deploy.yml` собирает `dist/` и публикует его в ветку `gh-pages` после push в `main`.

Публичный адрес:

```text
https://nst0v.github.io/bezvmyatin/
```

## Ограничения

- это неофициальный демонстрационный сайт;
- форма ничего не отправляет;
- цены, сроки, гарантии и реальные фотографии требуют подтверждения владельца;
- корпус здания намеренно не указан.
